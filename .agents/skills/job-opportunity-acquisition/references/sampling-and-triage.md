# Sampling and triage

## Vary the sample

A useful batch varies at least three of these dimensions:

- access route: direct employer, recruiter, technical community, referral lead;
- company shape: product company, agency/consultancy, startup, established team;
- role shape: frontend, UI/product engineer, junior full-stack, implementation, trainee;
- technology cluster: .NET UI, React/TypeScript, Svelte or framework-flexible, API integration;
- evidence route: portfolio, work sample, equivalent experience, named degree/years gate;
- work arrangement: Bangkok on-site/hybrid, Thailand remote, globally distributed, contract.

Variation is more valuable than arbitrary numerical ranking because it exposes how different systems make hiring decisions.

## Shallow capture fields

Record these before choosing a full analysis:

| Field | Question |
| --- | --- |
| Opportunity | What is the exact role, company, URL, source, and checked date? |
| Work hypothesis | What user or organizational problem might this role help solve? |
| Access hypothesis | Who may see the application first, and what evidence supports that guess? |
| Evidence adjacency | What can Mali truthfully point to now? |
| Learning yield | Which one to three concepts would transfer beyond this posting? |
| Friction | Which requirement or practical constraint may block immediate pursuit? |
| Unknown | What answer could most change the route? |
| Lane | Pursue, network-first, learning-rich, watch, or archive? |

## Lane meanings

- `pursue`: enough present evidence and practical access to justify a tailored next step.
- `network-first`: potentially worthwhile, but human context or a direct technical route should come before a formal application.
- `learning-rich`: weak or uncertain immediate fit, but unusually useful for transferable study, explanation, or a small demonstration.
- `watch`: incomplete timing, freshness, eligibility, or company information; revisit on a named date or trigger.
- `archive`: not worth active time now. Preserve the URL, date, reason, and any reusable market signal.

Do not make `archive` a trash bin for discomfort or unfamiliar terminology. State a concrete reason.

## Batch synthesis

After triage, report:

1. repeated work problems and concepts;
2. terms that are mostly implementation detail or marketing language;
3. common access and credential signals;
4. one learning project that covers several postings, if possible;
5. postings that deserve individual dossiers and why;
6. what the sample cannot establish about the wider market.
