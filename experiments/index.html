Tools, agents, frameworks, and working methods

Install less. Learn more from each installation.

Trying Hermes, OpenClaw, a new personal agent, a framework, or a local model can increase optionality—but only if the experiment answers a question and leaves behind understanding rather than a pile of configuration.

Required record

  • Tool, source, version, date, and reason for selection.
  • Question and success/failure criteria.
  • Environment and permissions, including files, browser, network, credentials, and external services.
  • Installation and complete uninstall/recovery path.
  • One bounded task using non-sensitive test data.
  • Observations, surprises, trade-offs, and comparison with the existing way of working.
  • Decision and the new option created: use, contribute, integrate, discuss, or discard.
Safety boundary: a fashionable personal agent is software with authority. Do not give it broad access to personal files, browsers, credentials, messaging, or paid services merely to “see what it can do.” Start isolated and expand only when a specific experiment requires it.
