# Job dossier template

Copy this directory to `jobs/<yyyy-mm-company-role>/` when a specific opportunity is supplied.

- Replace all bracketed placeholders in `analysis.html`.
- Add `source-notes.md` with the URL, accessed date, a concise posting summary, and any supplied screenshots/text.
- Add `learning-map.html` and `interview-kit.html` as the analysis matures.
- Create the learning application separately at `projects/<same-slug>/`.
- Link the completed dossier from `jobs/index.html`.
